This is a game based on the old arcade game Asteroids, created using Javascript and HTML5 Canvas.
You play the game as the spaceship, and you need to avoid the on-coming asteroids by using the arrow keys to move.
You shoot and break up the asteroids by using the space key.
You have three lives in total, each time an asteroid hits you, you lose a life.
The goal of the game is to shoot every asteroid remaining and stay alive.
